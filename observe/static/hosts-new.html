Confirm the Observe address

The install command tells a host where to reach Observe. Observe does not trust the address your browser used for this page, so confirm the address hosts should call. Write the scheme (http or https), then ://, then the host name or IP address and an optional :port, for example the host observe.example.com on port 8443. It is saved once and used for every command. Setting server.public_url in the Observe config does the same.
